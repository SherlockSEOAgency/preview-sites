Beveilig je e-mail en waarom je paswoord niet voldoende is.

Waarom je NU een passkey moet instellen voor je Google-account

Google bevestigde (eindelijk) een nieuwe aanval op Gmail-gebruikers, waarbij hackers gebruikmaken van geavanceerde phishingtechnieken én een kwetsbaarheid in Google’s infrastructuur. Zelfs e-mails die er 100% legitiem uitzien, blijken gevaarlijk te kunnen zijn.

Waarom is dit ernstig?

Zelfs als je 2-stapsverificatie (2FA) hebt via sms, kunnen aanvallers tegenwoordig:

  • jouw wachtwoord + code onderscheppen
  • zich voordoen als Google zelf
  • je overtuigen gevoelige info in te vullen op nagemaakte websitesEen wachtwoord is niet meer voldoende. Ook 2FA via sms raakt achterhaald.

De oplossing: gebruik een passkey. Een passkey vervangt je wachtwoord door een veilige login dewelke is gekoppeld aan je fysieke apparaat. Deze passkey werkt dus alleen op jouw toestel (smartphone, laptop, tablet).

Zelfs als hackers je wachtwoord weten én je sms-code kunnen onderscheppen, zonder jouw toestel komen ze er niet in.

Zo stel je een passkey in bij Google:

Stap 1: Ga naar je Google-account instellingen

👉 https://myaccount.google.com/security

  • Moeilijkheidsgraad: makkelijk
  • Tijd: 3 minuten
  • Nodig: je smartphone en/of computer

Stap 2: Scroll naar “Inloggen bij Google”

Klik op “Passkeys”, ga hier rechtstreeks naartoe via deze link: https://myaccount.google.com/signinoptions/passkeys

Stap 3: Klik op “Passkey toevoegen”

Je krijgt een scherm om een toestel toe te voegen.

  • Op je smartphone: bevestig met je vingerafdruk, gezichtsherkenning of pincode
  • Op je laptop: volg de instructies om je toestel als veilige sleutel te registreren

💡 Tip: voeg meerdere toestellen toe, zoals je telefoon én laptop

Stap 4: Schakel SMS-2FA uit (optioneel, maar aanbevolen)

Gebruik liever een authenticator app (zoals Google Authenticator of Microsoft Authenticator) of de Google Prompt via je toestel.
