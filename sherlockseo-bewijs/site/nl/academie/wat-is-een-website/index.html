01 — Begrip

Definitie en werking

De letterlijke betekenis van website is ‘plek op het internet’. Een website is een verzameling pagina’s die toegankelijk zijn via het internet. Een website is bereikbaar via een domeinnaam of adres (URL).

Het adres en de website-inhoud zijn twee aparte zaken.

De broncode van de website wordt geplaatst op een server bij de hostingfirma (zeg maar een bedrijf dat computerruimte verhuurt). De naam van je webadres kan je kopen bij je hosting firma, maar evengoed via een registrar (zij handelen enkel in domeinnamen).

02 Soorten

Soorten websites

Een website kan bestaan uit één enkele pagina (ook wel “one-pager” genoemd), sommige websites kennen dan weer vele miljoenen pagina’s.

Een website is meestal informatief (voorbeeld: Wikipedia), commerciëel (voorbeeld: Amazon) of een helpdesk (voorbeeld: stackexchange). Een website verschilt in die zin van een applicatie dat een app kan gedownload worden uit bijvoorbeeld de Apple App store of de Google Play store.

03 — Mobiel

Mobiel en responsief

  1. Naast apps heb je ook mobiele websites; Enkele jaren geleden waren er geen mobiele websites, sinds de opkomst van de mobiele telefoons werden er mobiele websites ontwikkeld, dit is niet hetzelfde als een ‘responsive’ website. De responsive website wordt op alle apparaten weergegeven.
  2. De mobiele website kent een eigen adres (bijvoorbeeld met het voorvoegsel m. zoals hier wordt weergegeven -> m.voorbeeld.be). Het wordt niet meer aangeraden om een mobiele website te bouwen.

04 Techniek

Technische aandachtspunten

Een veel voorkomend SEO issue met betrekking tot het website adres zijn gebroken links. Als je na het klikken op een link wordt doorverwezen naar een adres dat geen inhoud herbergt en je komt op een ‘dode pagina’ terecht dan krijg je een (404) foutmelding.
