Wat is een API?

De term API is een acroniem en staat voor “Application Programming Interface”.

Denk aan een API als een menu in een restaurant. Het menu biedt een lijst van gerechten die u kunt bestellen, samen met een beschrijving van elk gerecht. Wanneer u aangeeft welke menu-items u wilt, doet de keuken van het restaurant het werk en voorziet u in een aantal afgewerkte gerechten. Je weet niet precies hoe het restaurant dat eten bereidt, en dat is ook niet echt nodig.

Een API geeft een lijst van een aantal bewerkingen die ontwikkelaars kunnen gebruiken, samen met een beschrijving van wat ze doen. De ontwikkelaar hoeft niet noodzakelijkerwijs te weten hoe bijvoorbeeld een besturingssysteem een “Save As” dialoogvenster opgebouwd heeft. Ze hoeven alleen maar te weten dat het beschikbaar is voor gebruik in hun app.

Dit is geen perfecte metafoor, aangezien ontwikkelaars hun eigen gegevens aan de API moeten verstrekken om resultaten te krijgen. Misschien is het meer een restaurant waar je een aantal van je eigen ingrediënten kunt leveren waar de keuken mee zal werken.

Het is over het algemeen wel accuraat. Met API’s kunnen ontwikkelaars tijd besparen. Dit helpt de hoeveelheid code te verminderen die ontwikkelaars nodig hebben om applicaties te creëren. Het helpt ook om meer consistentie te creëren tussen apps voor hetzelfde platform. API’s kunnen de toegang tot hardware- en softwarebronnen tot stand brengen.
