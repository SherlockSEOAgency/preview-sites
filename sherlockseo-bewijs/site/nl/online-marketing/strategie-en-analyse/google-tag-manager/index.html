Veelgestelde vragen

Wat je je misschien afvraagt

Heb ik een developer nodig voor Tag Manager?

Niet voor elke wijziging. Je beheert tags zonder in de code van je site aan te passen. Voor een dataLayer kan een developer nodig zijn.

Wat is het verschil met Google Analytics?

Tag Manager verzamelt en stuurt data door. Analytics toont ze. Analytics wordt vaak via Tag Manager ingeladen.

Is basistracking genoeg?

Enkel basisgebeurtenissen laat veel liggen. Een geavanceerde configuratie volgt wat voor jouw bedrijf telt, zoals formulieren, klikken op telefoonnummers en aankopen.
